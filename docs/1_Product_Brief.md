# Product Brief — CareerOS

## Product Overview
CareerOS is a job-search operating system designed to eliminate the manual work and cognitive overhead of managing a modern job search. Instead of relying on spreadsheets, Notion, browser bookmarks, and memory, users capture opportunities in one click and manage their entire search from a single workspace.

## Problem
Active job seekers juggle multiple job boards, ATS platforms, resumes, recruiter conversations, interview notes, and follow-ups across disconnected tools. This fragmentation leads to missed opportunities, poor follow-up discipline, duplicated work, and decision fatigue.

## Why Now
- Job searches increasingly span many ATS platforms.
- Professionals are applying to more roles than before.
- AI has improved content generation but not workflow execution.
- Browser extensions make seamless capture possible.

## Target Users
### Primary ICP
Software engineers (3–8 years experience) actively pursuing remote or international roles.

### Secondary Segments
- Product managers
- Designers
- Data professionals
- Career switchers

## Core Value Proposition
Capture any relevant job in seconds, automatically organize it, and execute your job search from one place without maintaining spreadsheets.

## Strategic Positioning
**Category:** Job Search Operating System

Not another tracker. Not another resume builder.

CareerOS focuses on execution rather than documentation.

## MVP Summary

### Core Wedge
One-click browser capture that automatically creates:
- Company
- Job
- Application
- Pipeline entry
- Next actions

### P0 Features
- Authentication
- Browser extension
- Job parsing
- Company management
- Job management
- Application pipeline
- Kanban workflow
- Resume upload
- Tasks & reminders
- Search & filtering

### Explicitly Excluded
- Gmail integration
- Calendar integration
- AI career coach
- Job discovery
- Mobile app
- Team collaboration

## Success Metrics
- Extension installation rate
- First job captured
- Weekly active users
- Applications managed
- Repeat capture rate
- Users replacing spreadsheets

## Long-Term Vision
CareerOS evolves from a job-search workflow tool into a career operating system that helps professionals manage opportunities, relationships, interviews, and career transitions over many years.

## Differentiators
- Workflow-first instead of tracker-first
- Browser-native capture
- Automation over manual entry
- Built for execution
- AI added only where it meaningfully improves decisions

## Biggest Risks
1. Users continue using spreadsheets.
2. Browser parsers become unreliable.
3. Retention falls after users secure employment.
4. Feature creep slows learning.

## Guiding Principles
1. Optimize for execution, not documentation.
2. Automation over manual entry.
3. Ship fast and learn faster.
4. Build only what validates the core workflow.
5. Every feature must improve activation or retention.

## North Star
Help users consistently execute the highest-impact next action in their job search.
